# Redação de Manuais do Handbook (Documentation Prompt)

Este prompt genérico estabelece as regras de portabilidade de links markdown relativos e de responsabilidade única para a criação ou alteração de manuais técnicos de engenharia.

---

## 🔗 Roteiro de Criação Documental

*   **Identificação de Redundâncias:** Assegurar que os conceitos a serem documentados não existam de forma definitiva em outro manual do Handbook.
*   **Aplicação de Portabilidade:** Configurar todos os caminhos utilizando referências relativas portáveis (sem `file:///` ou diretórios absolutos locais).
*   **Estrutura de Links:** Ligar o novo documento de forma concisa aos manuais relacionados por meio de seção dedicada no rodapé.
