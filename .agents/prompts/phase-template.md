# Template de Planejamento de Fase (Phase Template Prompt)

Este prompt estabelece o modelo de instrução para planejar o escopo técnico, cronograma de tarefas incrementais e critérios de Definition of Done (DoD) para novas iterações de desenvolvimento.

---

## 📝 Diretrizes de Planejamento

*   **Leitura de Contexto:** Antes de desenhar o plano, ler obrigatoriamente a governança [project-governance.md](../rules/project-governance.md) e o snapshot [project-status.md](../memory/project-status.md).
*   **Isolamento de Escopo:** O plano de tarefas deve limitar-se estritamente à fase correspondente, definindo de forma unívoca quais arquivos serão criados ou editados.
*   **Critérios de Homologação (DoD):** Estabelecer checagens físicas obrigatórias de integridade, testes de QA e elaboração de relatório final de conformidade para o encerramento.
