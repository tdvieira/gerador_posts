# Modelo de Planejamento de Fase (Prompt de Modelo de Fase)

Este prompt estabelece o modelo de instrução para planejar o escopo técnico, cronograma de tarefas incrementais e critérios de Definição de Concluído para novas iterações de desenvolvimento.

---

## 📝 Diretrizes de Planejamento

*   **Leitura de Contexto:** Antes de desenhar o plano, ler obrigatoriamente a governança [project-governance.md](../rules/project-governance.md) e o snapshot [project-status.md](../memory/project-status.md).
*   **Isolamento de Escopo:** O plano de tarefas deve limitar-se estritamente à fase correspondente, definindo de forma unívoca quais arquivos serão criados ou editados.
*   **Critérios de Homologação (Definição de Concluído):** Estabelecer checagens físicas obrigatórias de integridade, testes de garantia de qualidade (QA) e elaboração de relatório final de conformidade para o encerramento.
