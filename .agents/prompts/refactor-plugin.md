# Refatoração do Core do Plugin (Plugin Refactor Prompt)

Este prompt orienta a simplificação e reestruturação sob responsabilidade única (SRP) no controlador principal PHP e nas views do plugin.

---

## 🧼 Diretrizes de Refatoração do Plugin

*   **Helper Functions:** Isolar trechos de códigos que processam cabeçalhos ou imagens em funções PHP focadas.
*   **Performance CSS/JS:** Otimizar seletores Javascript e simplificar declarações de layout administrativo no CSS.
*   **Validação Estática:** Assegurar que nenhuma alteração quebre as regras de capabilties do WordPress.
