# Security Policy

## Supported Versions

Only the latest released version of the plugin is supported and receives security updates.

| Version | Supported |
| :--- | :--- |
| v1.0.0 | Yes |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please **do not open a public issue**. Instead, report it privately directly to the author:

*   Email: **contato@tdvieiradesign.com**

Please include:
*   Steps to reproduce the vulnerability.
*   Potential impact.
*   Suggested mitigations (if available).

We will acknowledge receipt of your report within 48 hours and coordinate a patch release.
